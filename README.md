# Sumit18X Portfolio

Premium Vite + React portfolio for **sumit18x.dev**.

## Stack
- React 18
- Vite
- Lucide React
- Responsive CSS
- Dark / light mode
- Project filtering + search
- Command palette (`Ctrl/Cmd + K`)
- 100+ project positioning with curated featured projects
- MERN, AI/ML, Data Science, Data Analytics, Automation and Vibe Coder sections

## Local
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm run preview
```

## Deploy
Import the repository into Vercel. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.

The resume is included at `public/resume.pdf`.
